# HPB Trials

An overview of key randomised controlled trials in HPB surgical oncology for fellows and senior residents, tiered must know, good to know and nice to know.

Curated by Bas Groot Koerkamp, Erasmus MC, Rotterdam ([@basgrootkoerkam](https://x.com/basgrootkoerkam)).

**For educational purposes only; not medical advice.** For patient care, use the current guidelines and the original publications.

## Files

- `index.html`: the app
- `trials1.js`, `trials2.js`: the trial database (pancreas; liver, biliary and other)
- `expert.js`: the expert quiz on outcome numbers
- `manifest.webmanifest`, `sw.js`, icons: home-screen install and offline use

## Updating

Replace the changed files in this repository (Add file > Upload files). GitHub Pages republishes within a minute or two; users get the new version the next time they open the app online.
